# Support

Compass is a personal collection of agent skills shared as a reference. Support
here concerns the collection's behavior and source, rather than general agent
product questions.

For a skill issue, include the skill, task, model and harness when known, the
behavior you expected, and the relevant result or correction. A concrete
session is more useful than a general claim that an instruction is too long
or too short.

Use `SECURITY.md` for secrets, credentials, private state, or guidance that
crosses an authority boundary.

For an adoption request, link the upstream artifact and describe the gap it
would address. Project-specific behavior belongs in the project using it.

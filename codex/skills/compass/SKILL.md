# Compass

Work in [ariobarin/compass](https://github.com/ariobarin/compass). Read its root
`AGENTS.md`, current manifest, and the files that own the request before deciding
what to change.

Turn the request into the smallest coherent Compass update. Let the repository
own placement, verification, and pull request practice. Do not cache its rules
here. Keep project-specific lessons in the project that uses them.

Read `codex/skills/write-a-skill/SKILL.md` when creating or revising a skill.
For adoption, inspect the current upstream artifact and retain its provenance
and license notices. Follow the scope and delivery authority in the request.

# Grilling

Challenge the user's thinking until the decisions that matter are sound enough
to act on. Map this as a **design tree**: each decision branches into the
decisions that depend on it. Keep the tree to choices that could materially
change the outcome, scope, or next action.

Work the tree in **rounds**. The **frontier** is the unsettled decisions whose
prerequisites are already settled: questions you can ask now without guessing
at answers you have not heard yet. Ask a manageable batch of independent
frontier questions, numbered, with your recommended answer and its tradeoff.
Then wait for the user's answers.

Format each question like so:

```
❓ **Q1** - **<decision>**: <question and meaningful choices>

➡️ <recommended answer and why>
```

Each round reshapes the tree: settled decisions unblock their dependents and
retire alternatives the user has ruled out. A question whose answer depends on
another open question belongs to a later round. Reopen a settled decision only
when new evidence materially changes it.

Finding **facts** is your job. Look up what the environment and sources can
answer; delegate independent discovery when useful. A pending lookup blocks
only its dependent questions. Reserve questions for material **decisions** the
user owns. Apply their existing choices and delegated judgment yourself.

Stop when another answer is unlikely to materially change the outcome, scope,
or next action. State the settled decisions, consequential assumptions, and any
remaining blocker. Continue follow-on work the user has already authorized.
Ask only for a new material decision or authority that is still missing.

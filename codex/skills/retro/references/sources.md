## Adaptation Decisions

Retain the upstream focus on the environment and session evidence. Prefer the
smallest durable fix at its owner. Keep recommendations as the default while
honoring authority already given to apply them. Replace mandatory new checks,
rule tables, and a prescribed reviewer setup with Compass's risk and recurring
cost judgment. Keep skill authoring with Write A Skill and project lessons in
their project.
